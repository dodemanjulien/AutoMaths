# AutoMaths

Application gamifiée d'entraînement aux automatismes mathématiques pour le lycée professionnel (CAP et BAC PRO), conforme au référentiel de l'Éducation nationale.

**Lien élèves :** https://dodemanjulien.github.io/AutoMaths/

- 100 % HTML / CSS / JavaScript, sans dépendance ni compilation.
- Fonctionne hors-ligne après la première visite (service worker) et peut être ajoutée à l'écran d'accueil (iPhone : Partager → « Sur l'écran d'accueil »).
- `build.ps1` génère toujours la version fichier unique `automaths-standalone.html` pour un usage hors-ligne sur ordinateur.

Créé par Dodeman Julien.
